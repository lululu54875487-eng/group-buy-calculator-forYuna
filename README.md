# Yuna 團購湊團計算器

一個專為社群團購與多人湊單設計的純前端網頁工具，可計算優惠折數及各品項團購價、核對總金額，並產生能直接貼到社群的認購清單。

目前版本：**Ver 1.5**

不需安裝 App、不需登入，也不會將資料傳送到伺服器。下載後直接開啟 `index.html` 即可使用。

## 主要功能

- 自動加總團購品項原價並計算優惠折數
- 依折數自動計算各品項團購價
- 支援手動調整團購價，調整過的欄位會顯示黃底
- 可複製品項、上下調整順序及自動重新編號
- 可依完整品名一次設定所有同名品項價格
- 支援不參與折數計算的加購品
- 支援贈品及平均折入團購價
- 可加入寄送方式與運費
- 自動核對主購結帳金額與湊團總價
- 一鍵產生可貼到社群的認購清單
- 可貼回舊認購清單，快速重新建立品項
- 可依認購者整理個人明細、小計與總金額
- 支援手機及電腦版面

## 快速開始

1. 下載專案並開啟 `index.html`。
2. 輸入團購品項優惠總金額及折扣碼金額。
3. 新增團購品項並填寫品名與原價。
4. 按下「團購價計算」。
5. 視需要加入加購品、贈品及寄送資訊。
6. 確認湊團總價顯示 `✅`。
7. 按下「一鍵複製認購清單」，貼到社群供成員認購。
8. 收單後使用「整理成明細資料」，產生每位成員的明細與小計。

## 金額計算

優惠折數計算方式：

```text
(團購品項優惠總金額 - 折扣碼金額) / 團購品項原價總金額
```

系統會依折數計算每筆團購價。若四捨五入造成總額差異，可手動微調團購價；手動調整的欄位會以黃底標示。

按下「團購價計算」會解除手動價格並重新計算全部團購品項，請確認後再操作。

## 品項類型

### 團購品項

參與優惠折數計算，可填寫品名、原價及團購價。支援複製、刪除、上下移動與同名品項快速設定價格。

### 加購品

不參與優惠折數計算，但金額會計入主購實際結帳金額與湊團總價。

### 贈品

可記錄贈品名稱與金額，並選擇是否將贈品金額平均折入所有團購品項。

## 匯入認購清單

按下團購品項區的「匯入認購清單」，貼上先前保留的清單，即可快速重建品項，避免網頁重新整理後逐筆輸入。

匯入規則：

- 每行需包含編號、品名、`$價格` 與 `➡️`。
- 所有項目一律加入「團購品項」區。
- `【贈】`、`贈-`、`【加購】` 等前綴會保留在品名中。
- 箭頭後方的姓名或 `+0` 會保留，重新複製清單時仍會輸出。
- 空白的箭頭可以正常匯入。
- 清單前方的公告或說明文字會忽略。
- 編號不連續時會顯示缺號提醒。
- 匯入會取代目前頁面上的品項，若已有資料會先詢問確認。

建議保留完整清單，至少包含：

```text
優惠組合金額💰7657
折扣碼💰0
折數：0.5436

1. 商品名稱 $522 ➡️認購者

主購實際結帳金額💰7657
湊團總價💰7657✅
```

若清單缺少優惠組合金額或折數，品項與團購價仍可匯入，但系統無法準確還原原價，畫面會顯示提醒。

## 一鍵複製認購清單

輸出的認購清單包含：

- 寄送方式與運費
- 優惠組合金額與折扣碼
- 折數
- 團購品項、加購品及贈品
- 主購實際結帳金額與湊團總價
- 每筆品項後方供填寫認購者的箭頭

## 火速整理明細

將箭頭後已填姓名的認購清單貼入「整理成明細資料」，系統會依認購者分組，列出品項、個人小計與總金額。

整理前會自動：

- 清除每行前後的空白
- 忽略空白行及清單尾端摘要
- 將被換行拆開的 `$價格` 或 `➡️姓名` 接回上一筆
- 清除品名與姓名前後的多餘空白
- 保留品名中必要的空格，例如 `PDRN 3入`

支援的基本格式：

```text
1. 商品名稱 $100 ➡️小明
```

## 資料與使用限制

- 本工具為純前端單頁網頁，重新整理或關閉頁面後，尚未複製保存的內容會消失。
- 建議輸入完成後先使用「一鍵複製認購清單」保存文字。
- 匯入功能會依文字內容還原資料；缺少原價、折數或摘要時，部分欄位只能推算。
- 金額較大或需要正式對帳時，仍建議保留原始訂單、付款紀錄及最終認購清單。
