# Yuna 團購湊團計算器

一個專為社群團購、多人湊單與認購清單整理設計的純前端網頁工具。可自動計算優惠折數、分攤各品項團購價、記錄加購品與贈品、核對總金額，並產生可直接貼到社群的認購清單。

目前版本：**Ver 1.5**

免安裝、免登入、免伺服器。下載後直接開啟 `index.html` 即可使用，資料只會留在瀏覽器畫面中，不會上傳。

## 主要功能

- 自動加總團購品項原價，計算優惠折數
- 依折數自動換算各品項團購價
- 支援手動調整團購價，手動欄位會以黃底標示
- 支援一鍵重新計算所有團購價
- 支援複製品項、刪除品項、上下移動排序與自動重新編號
- 可依完整品名一次套用同名品項價格
- 支援不參與折數計算的加購品
- 支援贈品金額記錄，並可選擇是否平均折入團購品項
- 可記錄寄送方式與運費，並輸出到認購清單
- 自動核對主購實際結帳金額與湊團總價
- 一鍵複製可貼到社群的認購清單
- 可貼回既有認購清單，快速匯入品項與認購者
- 可依認購者整理個人明細、小計與總金額
- 支援手機與桌機版面

## 快速開始

1. 開啟 `index.html`。
2. 輸入「團購品項優惠總金額」與「折扣碼金額」。
3. 新增團購品項，填寫品名與原價。
4. 按下「團購價計算」或讓系統自動計算品項團購價。
5. 視需要新增加購品、贈品、寄送方式與運費。
6. 確認「主購實際結帳金額」與「湊團總價」是否一致。
7. 按下「一鍵複製認購清單」，貼到社群讓大家認購。
8. 收到填寫後的認購清單後，可使用「火速整理明細」產生個人明細。

## 金額計算邏輯

優惠折數：

```text
(團購品項優惠總金額 - 折扣碼金額) / 團購品項原價總金額
```

團購品項團購價：

```text
品項原價 x 優惠折數
```

主購實際結帳金額：

```text
團購品項優惠總金額 - 折扣碼金額 + 加購品總額
```

湊團總價會加總所有團購品項、加購品與需要分攤的贈品金額，並顯示核對結果。

## 品項類型

### 團購品項

參與優惠折數計算。可填寫品名、原價與團購價，並支援複製、刪除、上下移動排序與同名品項快速套價。

### 加購品

不參與優惠折數計算，但會加入主購實際結帳金額與湊團總價。適合用來記錄另外加買、補差額或固定金額品項。

### 贈品

可記錄贈品名稱與金額。若勾選平均折入，贈品金額會平均分攤到團購品項價格中，用於處理贈品成本或折抵分攤。

## 手動價格與重新計算

團購價欄位可以手動修改。手動修改後欄位會顯示黃底，代表該價格已被鎖定，不會在一般計算時被覆蓋。

若想重新依目前折數計算全部品項，請按「團購價計算」，系統會清除手動鎖定並重新產生團購價。

## 同名品項快速套價

在「一鍵設定同名品項價格」區塊輸入完整品名與指定價格，即可將所有名稱完全相同的團購品項一次改成同一價格。

注意：目前使用完整品名比對，若品名多空格、不同標點或文字不同，系統會視為不同品項。

## 匯入認購清單

可將先前由本工具產生、且已被填上認購者的清單貼回工具中，快速重建品項與認購者。

匯入支援的品項格式範例：

```text
1. 商品名稱 $100 ➡️小美
2. 【加購】商品名稱 $50 ➡️小華
3.【贈】贈品名稱 $0 ➡️
```

匯入時會嘗試讀取：

- 優惠組合金額
- 折扣碼
- 折數
- 主購實際結帳金額
- 湊團總價
- 寄送方式
- 運費
- 品項名稱、價格與箭頭後方的認購者

若清單缺少折數或金額資訊，系統仍會匯入可辨識的品項，但可能無法準確反推原價，請依警示內容檢查。

## 一鍵複製認購清單

複製內容會包含：

- 寄送方式與運費
- 優惠組合金額
- 折扣碼
- 折數
- 團購品項
- 加購品
- 贈品
- 主購實際結帳金額
- 湊團總價與核對符號
- 提醒大家在箭頭後方填寫認購者

## 火速整理明細

可將已填寫認購者的清單貼入「火速整理明細」，系統會依認購者分組，輸出每個人的品項、小計與總金額。

支援格式範例：

```text
1. 商品名稱 $100➡️小美
2. 商品名稱 $200➡️小華
```

也支援同一商品底下用「一件 $金額 ➡️姓名」表示多位認購者：

```text
1. 商品組合
一件 $185➡️小美
一件 $185➡️小華
```

## 使用限制

- 本工具是純前端頁面，重新整理或關閉頁面後，尚未複製或自行保存的資料可能會遺失。
- 剪貼簿功能需要瀏覽器允許，部分瀏覽器在本機檔案模式可能會限制複製功能。
- 金額會經過四捨五入，品項較多時可能出現 1 至數元差異，請以核對提示為準。
- 匯入功能依文字格式判斷，若清單格式被大幅改寫，可能無法完整辨識。
- 同名快速套價採完整文字比對，不會自動模糊搜尋。
