# 抽獎機介紹文

## 社群貼文版

🎉 抽獎機小工具上線啦！

這是一個可以直接在網頁上使用的抽獎工具，不需要安裝 App，也不用登入帳號。打開網頁、貼上名單、按下抽獎，就可以快速完成抽獎流程，適合社群活動、團購回饋、留言抽獎、粉絲福利、直播活動或小型名單抽選使用。

✨ 主要功能：

- 可直接輸入或貼上參加名單
- 支援一次整理多筆名單
- 可快速開始抽獎
- 可顯示抽獎結果
- 可重新抽選或繼續抽下一位
- 可保留得獎紀錄，方便核對
- 可複製抽獎結果，方便貼回社群公告
- 使用方式簡單，手機和電腦都能操作
- 純網頁工具，下載後也方便自己保存備份

📌 適合使用情境：

- 社群留言抽獎
- 團購名單抽獎
- 粉絲福利抽獎
- 活動名額抽選
- 小禮物得獎者抽選
- 臨時需要公平抽人的場合

使用方式很簡單：

1. 打開抽獎機網頁
2. 貼上或輸入參加名單
3. 確認名單內容
4. 按下抽獎
5. 複製結果並公布

這個工具主要是為了讓抽獎流程更快、更清楚，也方便之後自己下載備份使用。  
如果之後有更新功能，也會放在 GitHub 上保存，避免檔案不見或版本混亂。

## GitHub 簡介版

這是一個簡單好用的網頁版抽獎機，適合社群活動、團購回饋、留言抽獎與小型活動名單抽選。

工具採用純前端網頁製作，開啟 `index.html` 就能使用，不需要後端伺服器，也不需要額外安裝套件。

## 功能特色

- 名單輸入：可貼上或輸入抽獎名單。
- 快速抽獎：按下按鈕即可抽出得獎者。
- 結果顯示：抽獎結果會直接顯示在畫面上。
- 得獎紀錄：方便保留已抽出的名單與核對結果。
- 結果複製：可將抽獎結果複製後貼到社群。
- 本機可用：下載後可直接開啟網頁檔使用。
- 跨裝置使用：手機、平板、電腦瀏覽器皆可操作。

## 使用方式

1. 下載此專案。
2. 開啟 `index.html`。
3. 輸入或貼上抽獎名單。
4. 按下抽獎按鈕。
5. 複製結果並公布。

## 備註

此工具適合一般社群活動與小型抽獎使用。若正式活動需要完整稽核紀錄，建議另外保存原始名單、抽獎時間與公布截圖。
