# Yuna 團購湊團計算器

這是一個給團購湊團使用的網頁版計算工具，可以協助快速計算優惠折數、各品項團購價、加購品、贈品折入金額，並一鍵產生可貼到社群的認購清單。

工具是純前端網頁，下載後開啟 `index.html` 就能使用，不需要安裝 App，也不需要登入帳號。

## 社群貼文版

✨ Yuna 團購湊團計算器上線啦！

這是一個專門用來整理團購湊團金額的小工具，可以幫忙計算優惠折數、各品項團購價、加購品、贈品折入，還能一鍵複製認購清單，貼到社群後大家就可以直接在箭頭後面認購。

適合團購開團、湊免運、湊優惠組合、整理多人認購名單時使用。

主要功能：

- 自動計算優惠折數
- 自動加總團購品項原價
- 依照折數自動計算每個品項的團購價
- 可手動調整單一品項團購價
- 手動調整過的欄位會以黃底提示
- 可一鍵重新計算全部團購價
- 修改團購品項優惠總金額時，會自動強制重新計算團購價
- 可複製同一個品項，方便重複品名快速新增
- 可用完整品名快速套用同名品項價格
- 支援加購品，加購品不列入優惠折數計算
- 支援贈品，可選擇是否平均折入團購價
- 可輸入寄送方式與運費
- 可顯示主購實際結帳金額
- 可顯示湊團總價，並用符號提示金額是否吻合
- 若因四捨五入造成誤差，會顯示提醒
- 可一鍵複製社群用認購清單
- 可將認購清單整理成每位成員的明細與小計
- 手機與電腦都可以使用

使用方式：

1. 輸入團購品項優惠總金額
2. 輸入折扣碼或購物金金額
3. 在下方新增團購品項並輸入原價
4. 按下團購價計算
5. 視需要加入加購品或贈品
6. 確認湊團總價是否顯示正確
7. 按下一鍵複製認購清單
8. 貼到社群，讓大家在箭頭後方填名字
9. 收單後可用明細整理功能，整理每個人的認購品項與金額

這個工具主要是為了讓湊團金額更清楚、減少手算錯誤，也方便主購快速產生認購清單和整理明細。

## 功能說明

### 優惠折數計算

輸入：

- 團購品項優惠總金額
- 折扣碼金額
- 各團購品項原價

系統會自動加總團購品項原價，並計算折數：

```text
(團購品項優惠總金額 - 折扣碼金額) / 團購品項原價總金額
```

### 團購品項

團購品項會參與折數計算。每一筆品項可輸入：

- 品項名稱
- 原價
- 團購價

團購價可以自動計算，也可以手動調整。手動調整後欄位會顯示黃底，方便辨識哪些金額不是系統自動計算。

### 一鍵重新計算

按下「團購價計算」後，會重新依照目前折數計算全部團購品項價格。

修改「團購品項優惠總金額」時，也會自動執行重新計算，避免金額改了但舊的手動團購價仍被保留。

### 同名品項快速設定價格

如果有多個品項名稱完全相同，可以在快速設定區輸入完整品名與價格，一次套用到所有相同品名的團購價欄位。

### 加購品

加購品不參與優惠折數計算，但會計入主購實際結帳金額與湊團總價。

適合用在：

- 加購商品
- 另外加買的品項
- 不跟主優惠一起打折的商品

### 贈品

贈品可以輸入名稱與金額，並選擇是否平均折入團購價。

如果勾選平均折入，系統會將贈品金額平均分攤到團購品項中，方便處理主購希望把贈品價值平均反映在各品項金額的情境。

### 寄送資訊

可填寫：

- 寄送方式
- 運費

複製認購清單時，寄送資訊會一起帶入文字內容，方便社群公告。

### 金額核對

系統會顯示：

- 主購實際結帳金額
- 湊團總價
- 金額是否吻合

如果因四捨五入造成差額，畫面會提示需要手動微調部分團購價，讓總額核對正確。

### 一鍵複製認購清單

可產生適合貼到社群的認購格式，包含：

- 寄送資訊
- 優惠組合金額
- 折扣碼金額
- 折數
- 團購品項
- 加購品
- 贈品
- 主購實際結帳金額
- 湊團總價

每個品項後方會保留箭頭，讓成員直接在後面填名字認購。

### 明細整理

可將已填寫名字的認購清單貼回工具中，整理成每位成員的認購明細與小計，方便收單後核對金額。

## 使用方式

1. 下載此專案。
2. 開啟 `index.html`。
3. 輸入團購金額、折扣碼與品項原價。
4. 按下「團購價計算」。
5. 視需求新增加購品、贈品與寄送資訊。
6. 確認湊團總價。
7. 按下「一鍵複製認購清單」貼到社群。
8. 收單後可使用「整理成明細資料」產生成員明細。

## 適合情境

- 團購湊團
- 湊優惠組合
- 湊免運
- 多人認購同一批商品
- 主購整理認購清單
- 社群團購金額核對

## 備註

此工具適合一般社群團購與小型湊團使用。若金額較大或需要正式對帳，建議另外保存原始訂單截圖、付款紀錄與最終認購清單。
